
# IT Help Desk Toolkit

## Project Overview

The purpose is to simplify common IT troubleshooting
tasks using an interactive menu.

## Features
- View computer information
- Test internet connectivity
- Check available disk space
- Display running Windows services
- Interactive menu for easy navigation

## How to Run
    .\HelpDeskToolkit.ps1

## PowerShell Concepts Demonstrated
- Functions
- Variables
- Conditional statements
- Switch statements
- Do-while loops
- PowerShell pipelines
- Windows administration commands

## What I Learned
This project helped me understand how to organize
PowerShell commands into reusable functions and
create an interactive script.

I also practiced using VS Code and GitHub to
manage and document my code.
