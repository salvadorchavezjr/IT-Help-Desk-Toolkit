
# IT Help Desk Toolkit

## Project Overview
This project is a beginner-friendly PowerShell toolkit
created during the Microsoft Software & Systems Academy
(MSSA) program.

The purpose is to simplify common IT troubleshooting
tasks using an interactive menu.

## Features
- View computer information
- Test internet connectivity
- Check available disk space
- Display running Windows services
- Interactive menu for easy navigation

## Technologies Used
- PowerShell
- Visual Studio Code
- Git and GitHub
- Windows

## How to Run
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open a PowerShell terminal.
4. Run the following command:

    .\HelpDeskToolkit.ps1

5. Select an option from the menu.

## PowerShell Concepts Demonstrated
- Functions
- Variables
- Conditional statements
- Switch statements
- Do-while loops
- PowerShell pipelines
- Windows administration commands
